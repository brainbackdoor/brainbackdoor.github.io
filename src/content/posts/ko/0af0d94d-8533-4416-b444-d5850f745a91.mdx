## 2&#46; 서버간 ssh 연결 구성

<ul>

<li id="55acd0bf-d82b-4e78-8cc7-e9ac63e79fcc">

<p>systems manager를 활용하여 Bastion 구성을 하셔도 좋습니다&#46; 해당 내용은 <span className="notion-color-blue"><strong><a href="https://www.youtube.com/watch?v=ydJkCZd5OcU">영상</a></strong></span>을 참조하세요&#126; 🙏🏻</p>

</li>

<li id="cdce9be1-5203-4f27-99e4-ed4e2b4efbe5">

<p>Bastion Server로 사용할 별도의 EC2를 생성하고, Bastion Server에서 서비스용 서버에 ssh 연결을 설정해봅시다&#46;</p>

<span id="97fc800b-8388-4e42-8421-04a8dc3eaa06"></span>

```bash
## Bastion Server에서 공개키를 생성합니다.
bastion $ ssh-keygen -t rsa
bastion $ cat ~/.ssh/id_rsa.pub

## 접속하려는 서비스용 서버에 키를 추가합니다.
$ vi ~/.ssh/authorized_keys

## Bastion Server에서 접속을 해봅니다.
bastion $ ssh ubuntu@[서비스용 서버 IP]
```

</li>

<li id="09e3ab79-a484-40d1-85f0-f0ac38ef8bad">

<p>Bastion Server는 자신의 로컬 PC 공인 IP에서만 22번 포트로 접근이 가능하도록 Security Group을 설정합니다&#46;</p>

</li>

<li id="9f9ca5d6-3d7c-4d3d-9f19-b18d7090c4e7">

<p>서비스용 서버에 22번 포트로의 접근은 Bastion 서버에서만 가능하도록 Security Group을 설정합니다&#46;</p>

</li>

<li id="81b56842-142b-4a6d-bcc2-f89196d5289b">

<p>Bastion 서버에서 다른 서버에 접근이 용이하도록 별칭을 설정합니다&#46;</p>

<span id="2ca30cdc-9a0d-453d-b118-3e708247c0a6"></span>

```bash
bastion $ vi /etc/hosts
[서비스용IP]    [별칭]

bastion $ ssh [별칭]
```

</li>

</ul>

## 3&#46; 서버 환경설정 해보기

<p id="c319e5a3-aabb-44fb-acb7-9b72b284231a"><strong>A&#46; 환경변수 적용하기</strong></p>

<ul>

<li id="7594fade-451d-48fc-913b-e6537dabf510">

<p>Session Timeout 설정을 하여 일정 시간 작업을 하지 않을 경우 터미널 연결을 해제할 수 있습니다&#46;</p>

<span id="f674a554-25a1-4613-8f8f-1a5e09824768"></span>

```bash
$ sudo vi ~/.profile
  HISTTIMEFORMAT="%F %T -- "    ## history 명령 결과에 시간값 추가
  export HISTTIMEFORMAT
  export TMOUT=600              ## 세션 타임아웃 설정 
    
$ source ~/.profile
$ env
```

</li>

</ul>

<p id="a9f851c1-ba09-434b-ab4b-418a09d21002"><strong>B&#46; Shell prompt 변경하기</strong></p>

<ul>

<li id="c9388f8b-3e89-45ae-a0b3-4338d85e48ce">

<p>Bastion 등 식별해야 하는 서버의 Shell Prompt를 설정하여 관리자의 인적 장애를 예방할 수 있습니다&#46;</p>

<ul>

<li id="abbe0c77-497e-41d7-bcd9-eafcf1c7544d">

<p><span className="notion-color-blue"><a href="https://webdir.tistory.com/105">쉘변수</a></span></p>

</li>

<li id="d7cd9363-7c7e-4b1d-ab71-d4fa8d55a799">

<p><span className="notion-color-blue"><a href="http://ezprompt.net/">PS1 generator</a></span></p>

</li>

</ul>

<span id="aa79b4ba-1d2d-4e52-8932-15ac26f27efc"></span>

```bash
$ sudo vi ~/.bashrc
  USERNAME=BASTION
  PS1='[\e[1;31m$USERNAME\e[0m][\e[1;32m\t\e[0m][\e[1;33m\u\e[0m@\e[1;36m\h\e[0m \w] \n\$ \[\033[00m\]'

$ source ~/.bashrc
```

</li>

</ul>

<p id="17dab61c-5e6c-4792-9098-853602010051"><strong>C&#46; </strong><span className="notion-color-blue"><a href="https://zetawiki.com/wiki/%EB%A6%AC%EB%88%85%EC%8A%A4_logger"><strong>logger</strong></a></span><strong> 를 사용하여 감사로그 남기기</strong></p>

<ul>

<li id="b190389c-e85c-420a-bebb-4023a38177cd">

<p>서버에 직접 접속하여 작업할 경우, 작업 이력 히스토리를 기록해두어야 장애 발생시 원인을 분석할 수 있습니다&#46; 감사로그를 기록하고 수집해봅니다&#46;</p>

<span id="9bb231d3-a64d-48a1-82f7-ea5d743d96d7"></span>

```bash
$ sudo vi ~/.bashrc
  tty=`tty | awk -F"/dev/" '{print $2}'`
  IP=`w | grep "$tty" | awk '{print $3}'`
  export PROMPT_COMMAND='logger -p local0.debug "[USER]$(whoami) [IP]$IP [PID]$$ [PWD]`pwd` [COMMAND] $(history 1 | sed "s/^[ ]*[0-9]\+[ ]*//" )"'

$ source  ~/.bashrc
```

<span id="b7828db2-8bc0-48f5-900d-fe00e6a103fa"></span>

```bash
$ sudo vi /etc/rsyslog.d/50-default.conf
  local0.*                        /var/log/command.log
  # 원격지에 로그를 남기려면 어떻게 구성해야 할까요?
    
$ sudo service rsyslog restart
$ tail -f /var/log/command.log
```

</li>

</ul>

## 4&#46; 소스코드 배포, 빌드 및 실행해보기

<p id="8f77627f-82b1-4e50-bed7-99a8663d80ef"><strong>A&#46; 자바 설치</strong></p>

<span id="b7aaabd7-b2e3-4c79-b8fe-9c4ec92dd901"></span>

```bash
$ which java
$ sudo apt update
$ sudo apt install default-jre
$ sudo apt install default-jdk
```

<p id="0800f5b4-aa25-44ef-8782-f7b58ef82b08"><strong>B&#46; 빌드</strong></p>

<span id="2dafaf0e-d118-4365-9947-cdd18109822c"></span>

```bash
$ git clone [저장소]
$ cd [저장소]
$ ./gradlew clean build

# jar파일을 찾아본다.
$ find ./* -name "*jar"
```

<p id="6ac75430-7f82-4730-a389-1d28889daba6"><strong>C&#46; 실행</strong></p>

<span id="853c9c6f-a310-47f7-a5e7-69d3f9f12eae"></span>

```bash
$ java -jar [jar파일명] & 
  
# Application을 실행 후 정상적으로 동작하는지 확인해봅니다.
# 브라우저에서도 http://{서버 ip}:{port}로 접근해보세요.
$ curl http://localhost:8080
```

<ul>

<li id="2c7f6ae1-a89b-467b-9c3d-087d34b357b2">

<p>-<strong>Dserver&#46;port=8000</strong> 옵션을 활용하여 port를 변경할 수 있어요&#46;</p>

</li>

<li id="e7612cb1-578b-4b12-a7ac-f176b638863d">

<p>서버를 시작 시간이 너무 오래 걸리는 경우 -<strong>Djava&#46;security&#46;egd</strong> 옵션을 적용해보세요&#46;</p>

<span id="9e44c7f0-773b-4a6f-8291-0dcc4e853bae"></span>

```bash
$ java -Djava.security.egd=file:/dev/./urandom -jar [jar파일명] &
```

<ul>

<li id="b0c579eb-6473-425c-a31c-7e821986ebef">

<p><span className="notion-color-blue"><a href="https://lng1982.tistory.com/261">tomcat 구동 시 /dev/random 블로킹 이슈</a></span></p>

</li>

</ul>

</li>

<li id="90d62561-75b0-4e68-b3be-5a2744cb5274">

<p>터미널 세션이 끊어질 경우, background로 돌던 프로세스에 hang-up signal이 발생해 죽는 경우가 있는데요&#46; 이 경우 <span className="notion-color-blue"><a href="https://youngclown.github.io/2018/10/noup"><code><strong>nohup</strong></code></a></span>명령어를 활용합니다&#46;</p>

<span id="c9888f74-3448-432e-8aa1-b2bbf865aa16"></span>

```bash
$  nohup java -jar [jar파일명] 1> [로그파일명] 2>&1  &
```

</li>

</ul>

<p id="7098b0ab-1c33-4f3c-b43b-8c2965e2af33">D<strong>&#46; 종료</strong></p>

<span id="b06a1ffe-d670-486a-b4ca-6cb6fae5c599"></span>

```bash
# 프로세스 pid를 찾아봅니다.
$ ps -ef | grep java
$ pgrep -f java

# 프로세스를 종료합니다. 
$ kill -2 [PID]
```

## 5&#46; DNS 구성하기

<p id="d051e3d8-9b87-49ce-a523-1baccc5f232c"><strong><span className="notion-color-blue"><a href="https://xn--220b31d95hq8o.xn--3e0b707e/">무료 도메인 사이트</a></span></strong> 등을 활용하여 DNS 설정을 합니다&#46;</p>
