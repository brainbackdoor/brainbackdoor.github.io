# 전체 블로그 포스팅 애니메이션 적용 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 공개 글 58편의 검토 결과를 바탕으로, 정보량을 보존하면서 개념 이미지와 설명 과정을 애니메이션 도해로 대체한다.

**Architecture:** 기존 MDX·React·Canvas 도해와 공통 재생기를 사용한다. 글별 후보를 독립적으로 검토할 수 있는 도해 단위로 나누고, 사건표·정적 대체·움직이는 목업을 확인한 뒤 본문에 연결한다. 같은 개념은 상태 모델과 렌더링을 재사용하되 주제별 설명과 조건은 분리한다.

**Tech Stack:** 현재 저장소의 Astro, MDX, React, TypeScript, Canvas 2D, SVG, Vitest, Python 원문 대조 도구. 별도 애니메이션·차트 라이브러리 추가를 기본 전제로 하지 않는다.

**Spec:** [본문 애니메이션 작성 가이드와 58편 검토 결과](../../animated-figures.md). 1~8절은 표현·구현 기준, 9절은 글별 근거·이미지 처리 판단이다.

작성일: 2026-10-13. 기준 커밋: `b17fa00`. 현재 산출물은 실행 계획이다. 구현 코드·포스팅 본문·이미지·배포 설정은 이 계획 작성 단계에서 수정하지 않는다. 사용자 요청에 맞춰 구현 코드 예시 대신 작업 대상·사건·기대 결과·검수 순서를 명시했다.

## Global Constraints

- 기존 kciter 레퍼런스의 프레임·선·점·격자·사건에 따른 수치/주석 전개를 따른다. 표현 규격은 `docs/animated-figures.md` 1~4절을 사용한다.
- 단순 등장 효과 대신 이동·대기·상태·인과관계가 드러나는 도해를 작성한다.
- 본문·코드·표·첨부·출처·원래 이미지의 핵심 정보량을 줄이지 않는다.
- 개념 이미지는 대체를 우선하며, 실제 기록 사진·작품·설정 위치·측정 근거는 역할에 맞게 보존한다.
- 자동 재생하고 일시정지·속도·재생 조작 버튼을 추가하지 않는다. 소개성 문구와 불필요한 설명도 추가하지 않는다.
- 완성 상태 유지 기본값은 3초이며 정보량에 따라 늘린다. 모든 도해를 같은 반복 길이나 높이에 강제하지 않는다.
- 컨테이너 내부 폭 560px 미만에서 비교 패널은 1열로 전환한다. 데스크톱·390px·320px에서 검수한다.
- 화면 밖·탭 숨김에서는 프레임 작업을 멈추고, 동작 줄이기·JS 미사용·Canvas 실패에서는 읽을 수 있는 정적 대체를 제공한다.
- Canvas는 CSS 크기와 DPR을 분리한다. DPR 1·2, 폰트 로드·크기 변경을 검수한다.
- 움직임은 한 경과 시간에서 계산하며, 의미 있는 상태 변화가 있을 때만 DOM 설명을 갱신한다.
- 비교 조건·단위·시간 방향·연출 가정을 표시한다. 측정값을 추정하거나 임의의 성능 향상률을 만들지 않는다.
- 이벤트스토밍의 카드 색은 도메인 범례를 우선한다. 다른 도해의 오류/대기 색 의미와 혼합하지 않는다.
- 원본 파일·해시·블록 ID·앵커를 보존한다. 다시 수집해도 대체한 도해가 사라지지 않도록 연결 정보를 기록한다.
- 초안인 로드밸런서·영어 TCP 샘플, 비공개 외부 자료는 이번 공개 포스팅 적용 대상에서 제외한다.

### 연결 계약

- 기존 `AnimatedFigure`에는 `containerRef`, `title`, `caption`, `children`, `running`을 전달한다. 기존 홈 변형의 `variant`도 검수한다.
- 기존 `useFigurePlayback`은 `containerRef`, `durationMs`, `finalElapsedMs`, `enabled`, `onFrame`을 받고 `reducedMotion`, `running`, `redraw`를 반환한다.
- 에셋의 상태 계산은 경과 시간과 확정한 시나리오에서 같은 프레임을 반환하는 순수 계산으로 작성한다. 실제 데이터는 사전에 정규화하고 UI 상태에 결과를 프레임마다 누적하지 않는다.
- Canvas·정적 SVG·상태 설명은 같은 사건표와 좌표/값 정의를 참조한다. 정적 완성 장면 하나로 부족하면 여러 단계를 제공한다.
- MDX는 `client:visible`로 연결한다. 로드 이후 화면 밖 정지는 공통 재생기가 담당한다.
