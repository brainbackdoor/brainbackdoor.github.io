## 1단계 혼란스러운 탐험

<ul>

<li id="d62d0c54-c3c5-47ab-85a2-5297f9a43d22">

<p>알고 있는 도메인 이벤트를 작성합니다&#46;</p>

</li>

<li id="52b6c853-8d3f-486f-a760-328de65d181f">

<p>다른 사람과 토론을 시작하지 말고 자신이 옳다고 생각하는 방식으로 기록합니다&#46;</p>

</li>

</ul>

<span id="e0d3f7a3-517f-438e-9e6c-01131df2f823"></span>

#### Domain Event - 주황색

<figure id="5a412a41-b2b4-4d8e-8b80-e2f6aa342e28" className="notion-figure">

<img src="/content/c78ba22a-b64d-4016-9f09-c9de5f94e612/5a412a41-b2b4-4d8e-8b80-e2f6aa342e28.png" alt="" loading="lazy" width="748" height="352" />

</figure>

<ul>

<li id="26add193-372d-4981-b2c1-ea12abec9b5c">

<p>과거에 일어났던 일을 표현하기 때문에 과거 시제를 사용합니다&#46;</p>

<ul>

<li id="cf9da145-f6dc-472d-adeb-e06f959fed26">

<p>ex) 강의가 생성되었다&#46; 수강신청 성공 메일이 발송되었다&#46;</p>

</li>

</ul>

</li>

<li id="f51ffe0e-c1f9-4b5a-986e-1f138041af03">

<p>이벤트가 발생한다는 것은 상태가 변경되었다는 것을 의미합니다&#46;</p>

</li>

</ul>

## 2단계 타임라인 적용

<figure id="5b08cc27-e186-40f5-819f-bc354080bce2" className="notion-figure">

<img src="/content/c78ba22a-b64d-4016-9f09-c9de5f94e612/5b08cc27-e186-40f5-819f-bc354080bce2.png" alt="" loading="lazy" width="1070" height="394" />

</figure>

<ul>

<li id="c67158b9-454d-4c75-aa0a-e7eb65184d34">

<p>모든 도메인 이벤트를 타임라인으로 정렬하고 실제로 중복되는 이벤트를 제거합니다&#46;</p>

</li>

<li id="a3655373-f3a6-4584-a3ca-f5b035560703">

<p>시간은 왼쪽에서 오른쪽으로 흐르고, 위에서 아래로 평행한 시간을 표현할 수 있습니다&#46;</p>

</li>

</ul>

<span id="c5abca4e-29ce-41b1-a07b-c38efc8817a1"></span>

#### Hot Spot - 자주색

<figure id="1bf179cf-5db8-4ec3-bda3-b29b4d4b00c6" className="notion-figure">

<img src="/content/c78ba22a-b64d-4016-9f09-c9de5f94e612/1bf179cf-5db8-4ec3-bda3-b29b4d4b00c6.png" alt="" loading="lazy" width="410" height="316" />

</figure>

<ul>

<li id="47c8e9b6-4e24-42eb-b390-69b3eeb7039e">

<p>2단계에서 발생한 갈등을 시각화하고 캡처하는데 사용합니다&#46;</p>

</li>

<li id="b8a2639f-b3ab-43e7-bb80-94586447bf4a">

<p>당장 토론하지 않고 나중에 문제가 해결되면 제거합니다&#46;</p>

</li>

</ul>

<span id="d4d3b72b-afe2-4ee3-bea2-049068b78197"></span>

#### Actor - 노란색

<figure id="3a241b62-16c2-4fe7-8a19-db806e5ed976" className="notion-figure">

<img src="/content/c78ba22a-b64d-4016-9f09-c9de5f94e612/3a241b62-16c2-4fe7-8a19-db806e5ed976.png" alt="" loading="lazy" width="662" height="336" />

</figure>

<ul>

<li id="c9f11b7e-2337-47a9-883a-7704bdaf1c5c">

<p>단순한 사용자 또는 고객보다는 페르소나를 설정합니다&#46;</p>

</li>

</ul>

<span id="7a4f9b0d-81aa-40ad-bf3e-68617e579f73"></span>

#### System - 분홍색

<figure id="a20755e5-95cb-4edf-acbe-922fda4e69c3" className="notion-figure">

<img src="/content/c78ba22a-b64d-4016-9f09-c9de5f94e612/a20755e5-95cb-4edf-acbe-922fda4e69c3.png" alt="" loading="lazy" width="308" height="326" />

</figure>

<ul>

<li id="b43d955d-9695-4f4c-a7da-6bbde88d7a4b">

<p>외부 시스템부터 일부 레거시 및 마이크로서비스에 이르기까지 책임을 전가할 수 있는 모든 것을 의미합니다&#46;</p>

</li>

</ul>

<span id="a94ed29b-df3d-4e95-bd2f-b97bf092179d"></span>

#### Command or Action - 파란색

<figure id="d4f33c7c-6231-417f-9fe5-f3ed58d36324" className="notion-figure">

<img src="/content/c78ba22a-b64d-4016-9f09-c9de5f94e612/d4f33c7c-6231-417f-9fe5-f3ed58d36324.png" alt="" loading="lazy" width="704" height="268" />

</figure>

<ul>

<li id="2ab72b3c-25b5-4ec7-90b0-6483fc42de9f">

<p>시스템에서 일어나는 일</p>

</li>

<li id="77e4642b-1983-4987-9857-69d35de8f603">

<p>도메인 이벤트가 발생하는 원인</p>

</li>

</ul>

<span id="7a5dfedc-bc81-4670-98dc-0188c5eece43"></span>

#### Read Model or Info - 초록색

<figure id="23fcfdd1-dfca-4efe-85c1-e0a2222d93fc" className="notion-figure">

<img src="/content/c78ba22a-b64d-4016-9f09-c9de5f94e612/23fcfdd1-dfca-4efe-85c1-e0a2222d93fc.png" alt="" loading="lazy" width="344" height="330" />

</figure>

<ul>

<li id="fe5301a7-c22d-449a-b9f5-96b19a2ac36d">

<p>액터가 커맨드하는데 도움이 되는 정보 (결정을 내리는데 필요한 정보)를 의미합니다&#46;</p>

</li>

</ul>

<span id="6f9c2ecd-7aa3-4daa-8600-3b7c44f1b93c"></span>

#### Policy - 연보라색

<figure id="f05c51fd-d51a-455f-a5ab-b5dc34eec38c" className="notion-figure">

<img src="/content/c78ba22a-b64d-4016-9f09-c9de5f94e612/f05c51fd-d51a-455f-a5ab-b5dc34eec38c.png" alt="" loading="lazy" width="580" height="318" />

</figure>

<ul>

<li id="f825f891-dc45-402f-bc74-199c33f64025">

<p>주로 ‘&#126; 할 때마다’ 라는 단어로 시작합니다&#46;</p>

</li>

<li id="848facfb-3532-4c59-9574-38db9d7c4146">

<p>도메인 이벤트와 커맨드 사이에 위치합니다,</p>

</li>

<li id="1a2694b3-f37d-45a7-8284-1a6262857dd1">

<p>단순한 조건부터 복잡한 정책까지 모두 될 수 있어요&#46;</p>

</li>

</ul>

## 3단계 바운디드 컨텍스트를 확인

<ul>

<li id="d0879431-7d7f-4080-8508-c05fed709c70">

<p>경계를 나눕니다&#46;</p>

</li>

</ul>

<span id="a94c4a6c-40d1-40f3-b0b1-31dda1c5de64"></span>

#### Aggregate or Business Rules - 연노란색

<ul>

<li id="639a4384-752b-40c4-a9e7-9a743a89f392">

<p>시스템이 기대하는 책임을 수행하며 일관성을 유지하는 단위를 의미합니다&#46;</p>

</li>

<li id="777fa83c-bc1c-48dd-b3c7-14d7a4404b56">

<p>일관성은 항상 참이어야 하는 속성(불변식)을 유지함으로써 달성됩니다&#46;</p>

</li>

</ul>

<span id="32f7bc24-c511-4ad9-a777-08185f305cbe"></span>

#### 색상 규칙

<p id="9f46e6a3-53b1-412b-afc5-269d9a9ad3a5">일관된 색상규칙을 고수합니다&#46;</p>

<ul>

<li id="56356a7c-2464-4c1a-9096-8e84cb5625fb">

<p>파란색 → 주황색 사이에는 분홍색이 있어야 합니다&#46;</p>

<ul>

<li id="271b835f-18ac-4fa3-b251-84e0b07c0feb">

<p>시스템이 외부 시스템에 의존할 경우 그 이후에 도메인 이벤트가 발생하여야 합니다&#46;</p>

</li>

</ul>

</li>

<li id="73e751a1-8fdf-45f3-9c70-782e6365c8ee">

<p>주황색 → 파란색 사이에는 연보라색이 있어야 합니다&#46;</p>

<ul>

<li id="44446723-93a8-4779-acd4-d9fca128ad84">

<p>도메인 이벤트로 인해 시스템에서 연쇄적으로 액션이 일어난다면 그에 대한 정책이 필요할 수 있어요&#46;</p>

</li>

</ul>

</li>

</ul>
