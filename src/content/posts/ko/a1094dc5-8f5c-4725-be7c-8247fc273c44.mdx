## 1&#46; 온도 체크 (5&#126;10분)

<ul>

<li id="7e95d991-1610-4e7c-b60d-d17fce939882">

<p>본인의 현재 상태를 점검해 1&#126;5점의 숫자로 표시합니다&#46; 1점이 가장 안 좋은 상태, 5점은 가장 좋은 상태입니다&#46; </p>

</li>

<li id="60c0ef60-6dea-4e1c-8f89-fb00383d35b9">

<p>매긴 점수 자체에 대해 이야기 하기 보다는, 내가 매긴 점수보다 높은 점수가 아닌 이유와 낮은 점수가 아닌 이유를 설명해주세요&#46; 그랬을 때 더 이야기를 풀어나가기 쉽고 다른 사람도 이해하기 쉽습니다&#46;</p>

</li>

<li id="6767ef93-3770-4dc4-b1c1-dd0f88253089">

<p>온도 체크를 하는 이유는 서로의 상태를 파악하는 의미가 있습니다&#46; 회고는 이전 시간을 되돌아보면서 쉽게 감정적으로 될 수 있으므로, 서로의 상태를 먼저 살펴보는 것이 중요합니다&#46;  😉</p>

</li>

</ul>

<p id="4cdb8711-01b7-47ac-a137-0ff14f30c575"><strong>씨유</strong></p>

<span id="4584e8cc-afd5-494c-8955-55631dcecea5"></span>

```javascript
나는 3점이야. 아침에 지하철에 사람들이 너무 많아서 콩나물이 되어버린것 같아
```

## 4&#46; 액션 플랜 도출 (15&#126;20분)

<p id="28bd6883-c79b-407f-8b75-7b0f0ebdf1cf">이제는 선택의 시간입니다&#46; <span className="notion-color-yellow_background">회고의 목적에 맞게 잘한 일은 다음에 더 잘할 수 있게, 아쉬웠던 일은 다음에 더 잘할 수 있도록 구체적인 다음 할 일에 대해 이야기해볼겁니다&#46;</span>  </p>

<ol>

<li id="b72fb2ba-f5e8-4bcf-bde9-68ee2a10bf79">

<p>위의 그룹 중 투표를 통해 하나의 그룹을 선별해봅니다&#46;</p>

</li>

<li id="f838f925-b268-4c3a-b1d3-6138b92565f1">

<p>내일 당장이라도 실천할 수 있을 것 같은 액션플랜이 떠오르는 항목만 남겨봅니다&#46; </p>

</li>

<li id="f309e5b7-2603-4457-8398-506a28e214e7">

</li>

</li>
