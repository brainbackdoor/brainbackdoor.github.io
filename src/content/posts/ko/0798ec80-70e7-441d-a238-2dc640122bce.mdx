<p>생성한 인증서를 활용하여 Reverse Proxy에 TLS 설정을 해봅시다&#46; 우선 인증서를 Dockerfile이 있는 현재 경로로 옮깁니다&#46;</p>

<span id="faeb60fa-5620-4c1c-b973-e9bce0267854"></span>


</li>

<ul>

<li id="89b3f1b1-5fc3-426c-8026-e27234e83bc7">

<p>Dockerfile 을 아래와 같이 수정합니다&#46;</p>

<span id="cbe2b003-5307-4f35-b4e3-7c586c72ce0c"></span>

```bash
FROM nginx

COPY nginx.conf /etc/nginx/nginx.conf 
COPY fullchain.pem /etc/letsencrypt/live/[도메인주소]/fullchain.pem
COPY privkey.pem /etc/letsencrypt/live/[도메인주소]/privkey.pem
```

</li>

</ul>

<ul>

<li id="6326486e-a7c0-41b0-b76b-e0c45e87aa89">

<p>nginx&#46;conf 파일을 아래와 같이 수정합니다&#46;</p>

<span id="7c67fa0a-13a0-4b93-b385-0381b7b8b18a"></span>

```bash
events {}

http {       
  upstream app {
    server 172.17.0.1:8080;
  }
  
  # Redirect all traffic to HTTPS
  server {
    listen 80;
    return 301 https://$host$request_uri;
  }

  server {
    listen 443 ssl;  
    ssl_certificate /etc/letsencrypt/live/[도메인주소]/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/[도메인주소]/privkey.pem;

    # Disable SSL
    ssl_protocols TLSv1 TLSv1.1 TLSv1.2;

    # 통신과정에서 사용할 암호화 알고리즘
    ssl_prefer_server_ciphers on;
    ssl_ciphers ECDH+AESGCM:ECDH+AES256:ECDH+AES128:DH+3DES:!ADH:!AECDH:!MD5;

    # Enable HSTS
    # client의 browser에게 http로 어떠한 것도 load 하지 말라고 규제합니다.
    # 이를 통해 http에서 https로 redirect 되는 request를 minimize 할 수 있습니다.
    add_header Strict-Transport-Security "max-age=31536000" always;

    # SSL sessions
    ssl_session_cache shared:SSL:10m;
    ssl_session_timeout 10m;      

    location / {
      proxy_pass http://app;    
    }
  }
}
```

</li>

<li id="16f66104-1008-484b-9653-a1580ea0266d">

<p>방금전에 띄웠던 도커 컨테이너를 중지 &amp; 삭제하고 새로운 설정을 반영하여 다시 띄워봅시다&#46;</p>

```bash
$ docker run -d -p 80:80 -p 443:443 --name proxy brainbackdoor/reverse-proxy:0.0.2
```
