## Global Constraints

- 자동 재생하고 일시정지·속도·재생 조작 버튼을 추가하지 않는다. 소개성 문구와 불필요한 설명도 추가하지 않는다.
- 본문·코드·표·첨부·출처·원래 이미지의 핵심 정보량을 줄이지 않는다.
- 원본 파일·해시·블록 ID·앵커를 보존한다. 다시 수집해도 대체한 도해가 사라지지 않도록 연결 정보를 기록한다.
- 의미 상태는 검증된 사건표에서 계산한다. 표시 전환이 도착·쓰기·소유권·counter·복원 결과를 앞당기지 않는다.
- 새 지식16절을 우선한다. 외곽 카드·반복 텍스트 박스·고정 높이를 공통 필수로 사용하지 않는다.
- 파랑 흐름·초록 응답/완료·주황 대기·빨강 손실/오류와 별도 도메인 범례를 유지한다. 작은 글자 대비를 검수한다.
- 컨테이너 내부 폭560px 미만의 비교 1열을 기본으로 하되 모바일 장면을 별도로 구성한다. 데스크톱·390px·320px에서 검수한다.
- 화면 밖·탭 숨김에서 프레임을 멈춘다. 동작 줄이기·JS 미사용·Canvas 실패에서도 핵심 사건과 결론을 읽을 수 있다.
- 원자료 값·성능·프로토콜을 무작위화하지 않는다. 원본/설명용 조건을 명시한다.
- 모든 후속 묶음은 움직이는 시안을 먼저 확인한다. 지금은 문서까지 완료하며 시안·구현·배포는 실행 요청 이후 단계다.
