## 1&#46; 성능 테스트 도구

<p id="9c5f4aa5-89cd-4e54-882d-cfc39d23c2dc">성능 테스트 도구로는 Apache JMeter, nGrinder, Gatling, Locust, K6 등이 알려져있습니다&#46;</p>

<ul>

<li id="8d26b146-0e78-4420-a4bf-32e05e4ee6f5">

<p>시나리오 기반의 테스트가 가능해야 합니다&#46; (Apache JMeter는 단순히 일정량의 API를 요청하는 것으로, 로그인한 사용자의 요청 등의 시나리오를 구성하는데 한계가 있습니다&#46;)</p>

</li>

<li id="a16853c4-971e-4089-8748-b242a9b4e443">

<p>동시 접속자 수, 요청 간격, 최대 Throughput 등 부하를 조정할 수 있어야 합니다&#46;</p>

</li>

<li id="05e823e2-edc2-41ee-93b0-61d28cf50e95">

<p>부하 테스트 서버 스케일 아웃을 지원하는 등 충분한 부하를 줄 수 있어야 합니다&#46; (k6 standalone 방식은 지원하지 않습니다&#46;)</p>

</li>

</ul>

# smoke.js
import http from 'k6/http';
import { check, group, sleep, fail } from 'k6';

export let options = {
  vus: 1, // 1 user looping for 1 minute
  duration: '10s',

  thresholds: {
    http_req_duration: ['p(99)<1500'], // 99% of requests must complete below 1.5s
  },
};

const BASE_URL = '[Target URL]';
const USERNAME = 'test id';
const PASSWORD = 'test password';

export default function ()  {

  var payload = JSON.stringify({
    email: USERNAME,
    password: PASSWORD,
  });

  var params = {
    headers: {
      'Content-Type': 'application/json',
    },
  };


  let loginRes = http.post(`${BASE_URL}/login/token`, payload, params);

  check(loginRes, {
    'logged in successfully': (resp) => resp.json('accessToken') !== '',
  });


  let authHeaders = {
    headers: {
      Authorization: `Bearer ${loginRes.json('accessToken')}`,
    },
  };
  let myObjects = http.get(`${BASE_URL}/members/me`, authHeaders).json();
  check(myObjects, { 'retrieved member': (obj) => obj.id != 0 });
  sleep(1);
};

<ul>

<li id="8770d3e6-57c5-4fac-848c-a211b476b41a">

<p><strong>Throughput &#58; 1일 평균 rps &#126; 1일 최대 rps</strong></p>

<ul>

<li id="8629b71c-09f4-418f-ab9d-6fac09582c19">

<p>1일 사용자 수(DAU) x 1명당 1일 평균 접속 수 = 1일 총 접속 수</p>

</li>

<li id="26d54c53-624d-4d53-b793-5b9409f81879">

<p>1일 총 접속 수 / 86,400 (초/일) = 1일 평균 rps</p>

</li>

<li id="709f930d-f4e7-400c-bbb9-79c9301d76d1">

<p>1일 평균 rps x (최대 트래픽 / 평소 트래픽) = 1일 최대 rps</p>

</li>

</ul>

</li>

</ul>

</li>

<span id="41ee0d2b-8901-4a02-89ba-bf4fd066d0c2"></span>

### B&#46; VUser 구하기

<ul>

<li id="02706197-2043-4d29-91ac-dfcd5261ca9c">

<p>Request Rate&#58; measured by the number of requests per second (RPS)</p>

</li>

<li id="ecd400a4-5778-418a-8131-5aed0b4edd6e">

<p>VU&#58; the number of virtual users</p>

</li>

<li id="e10e9b22-0201-4e3a-a1cf-2207f6e8972b">

<p>R&#58; the number of requests per VU iteration</p>

</li>

<li id="2d30d721-b286-4325-9e89-ecd4280551e8">

<p>T&#58; a value larger than the time needed to complete a VU iteration</p>

</li>

</ul>

<span id="d9bcd433-7e90-4df4-a604-7fb0560e1e92"></span>

```text
T = (R * http_req_duration) + a

VUser = (목표 rps * T) / R
```

<ul>

<li id="a5b4db99-c1c5-45ee-8a1c-acc4bb2abd2f">

<p>가령, 시나리오상 두개의 요청 (<strong>R=2</strong>)이 있고, 요청별 평균 왕복시간이 0&#46;5s, 부하테스트상에 고려하지 않았지만 현실세계에서 발생하는 지연시간이 1초(a)라고 가정할 때 VUser의 iteration별 목표 응답시간은 2입니다&#46; 만약 이 때, 목표 rps가 300이라면, VUser는 300입니다&#46;</p>

<blockquote id="a8f1daa9-2aa6-442d-b121-1fd145ac97b5">

<p>VU = (300 &#42; 2) / 2 = 300</p>

</blockquote>
